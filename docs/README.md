# Documentación de HUIFAX

HUIFAX es "el teletipo de PichilemuTV.org": la pantalla que se emite durante el
tiempo fuera de aire del canal comunitario. Muestra información útil para la
comunidad en un carrusel a pantalla completa mientras suena de fondo una radio
online.

Este repositorio es una **nueva versión** desde cero. La versión anterior sigue
publicada en <https://tools.pichilemutv.org/huifax/>.
